## 状态流

```text
发现 → 查看详情 → 安装 → 加载/重启 → 枚举预设 → 兼容性检测
                                      ├─ 可绑定 → 新建 Bot 可选
                                      ├─ 部分兼容/待验证 → 显示限制
                                      └─ 不兼容 → 不进入可选列表
```

## 本原型不冻结的内容

- 插件发现列表的真实来源和安装接口。
- 检测执行是否需要重启或临时 profile。

群聊候选结构：群会话只做 relay；每个成员会话使用自己的预设。成员预设若不支持 relay 所需能力，报告为“仅支持单聊”。

最终行为及能力边界以[开发文档第 20 节](../../development/cross-module/plugin-presets-development.md)为准。群中继使用 `group_relay`，成员不需要自带该工具；不会据此误判成员仅可单聊。
