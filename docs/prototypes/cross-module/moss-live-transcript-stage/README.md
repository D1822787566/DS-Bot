# MOSS 实时字幕舞台低保真原型

文档状态：方向 C 已确认 / 正式实现前仍需细化交互

## 当前问题

现有常驻通话条只显示一条滚动字幕。用户希望像歌词轮播一样持续看到当前句、上一句和下一句。

## 已确认约束

- MOSS 先采用人工启动和人工切换。
- 一个 DS Bot 只能绑定一个 MOSS Profile。
- 通话中切换先结束当前通话，再切换目标 Profile。
- 练习结束不默认询问保存摘要；用户主动提出时再处理。

## 三个方向

- A：字幕剧场。把实时字幕提升为通话主舞台，当前句最大，前后句作为上下文。
- B：歌词轨道。模拟歌词滚动，字幕连续向上推进，当前句有明确的进度和高亮。
- C：双栏字幕。保留 Bot 聊天，把实时字幕作为独立的可读面板。

方向 C 已由用户确认。三个方向都只是低保真原型，不访问真实 MOSS、Bot、麦克风或模型。

方向 C 的当前页面融合稿见 [c-dual-pane-v2.html](c-dual-pane-v2.html)：沿用 DS Bot 页面壳层，桌面并行显示，窄窗口优先显示实时字幕，并用页签切换 Bot 聊天。

根据 `start.ps1` 启动后的真实 DS Bot 页面重新对齐的版本见 [c-integrated-current-page.html](c-integrated-current-page.html)。它使用真实页面中的 Bot 列表、华子聊天和输入区，再加入实时字幕面板。

当前交互调整为：不显示全局底部语音条，语音控制集中在 MOSS 实时字幕侧栏底部。

当前 Bot 详情侧栏入口交互见 [c-bot-details-moss-flow.html](c-bot-details-moss-flow.html)。它覆盖未绑定、已绑定、统一设置弹框和手动拨打中四种状态；插件页不作为当前 Bot 的主要入口。

最新调整：在 Bot 详情侧栏原有“详情 / 浏览器”页签位置增加“MOSS Live”页签。点击后直接进入当前 Bot 的 MOSS Live 设置界面；绑定后页签显示 Profile 状态和“拨打”入口，设置按钮仍打开统一设置弹框。
