# MOSS Live 常驻通话 · 视觉候选

状态：用户于 2026-11-12 回复「那就 A 吧」，[已确认 A 底部通话条](direction-approved.md)。三版 HTML 保留为原型历史，正式实现采用 A；实现验收记录见 [verification.md](verification.md)。

## 已确认交互

- 切换 DS Bot 页面时，保持原 MOSS 会话；返回时保留字幕、静音与共享状态，不重新连接或播放开场问候。
- 提供常驻状态、静音、返回和结束操作。共享时持续显示共享状态及停止共享入口。
- 明确结束、禁用插件或退出应用时停止会话并释放资源；不能简单删除页面清理逻辑。

## 三个候选

| 方向 | 结构 | 权衡 |
|---|---|---|
| A 底部通话条（建议） | 固定在主区域底部，位于聊天输入框下方 | 清晰、不遮内容；占用少量垂直空间 |
| B 悬浮胶囊 | 主区域右上方悬浮，可收起字幕 | 紧凑；可能遮挡同位置内容，须另评估正式页面 |
| C 侧栏通话卡 | 侧栏底部保留一张通话卡 | 聊天区完整；侧栏变短，窄窗口需改用底部条 |

通过 `index.html` 查看对比并进入任意一版。顶部可切换方向，左上角状态按钮可模拟聆听、说话、静音和屏幕共享。模型、Bot、麦克风、屏幕和联网调用均未接入。顶部状态切换仅供评审，不是正式产品控件。

## 品牌与素材依据

- 沿用 `ds-bot/src/client/themes.js` 的 DeepSeek 浅色主题及现有侧栏比例、灰色按钮、蓝色光球。
- 三个头像 SVG 由 `ds-bot/src/client/characters.js` 的 `characterMarkup` 和 `shapeOf` 生成，未另画品牌角色。
- 光球从插件现有 CSS 径向渐变和呼吸效果缩小适配。字体使用项目现有原生系统字体。
- Esther App 模板的侧栏/主区域结构作为组织参考；产品既有风格优先，不引入个人网站的纸纹、刊号、DFL 标识或衬线标题。

## 当前范围

本目录 HTML 只模拟布局与交互。正式实现已将通话归属提升到客户端根，页面仅订阅；切页保留原连接，结束/禁用/退出清理资源。摄像头、独立 Worker 和额外授权机制不在本次范围。
