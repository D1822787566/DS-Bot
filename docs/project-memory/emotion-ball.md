# Bot 表情球

## 模块目标

- [用户确认] 每个 Bot 有自己的表情球与固定身份色，Chief DS Bot 可以通过对话设计表情，共享表情库在面板中分类展示。
- [用户确认] 工作状态由系统事件驱动，情绪作为短时表达层组合；通过预览、修改、保存和分配完成设计。
- [用户确认] 表情球作为默认动态头像展示于侧栏、聊天顶部和群成员列表，详情面板提供放大展示；普通 Bot 自动选择已分配表情；修改表情保存为新版本，用户应用后才切换指定 Bot，其他 Bot 继续使用旧版本。
- [用户确认] 表情球集成现有 `ds-bot` 插件，内部划分表情定义与校验、表情管理与 Agent 工具、表情界面与动画三个模块；每个 Bot 通过独立配置区分，不新增独立的 DSH 插件。
- [代码证据] 完整设计见 [2026-11-06-emotion-ball.md](../plans/2026-11-06-emotion-ball.md)；下列实施基线用于续接，不代表已经实现。
